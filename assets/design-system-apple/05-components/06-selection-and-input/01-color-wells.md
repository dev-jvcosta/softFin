# Seletores de cor (Color wells)

> Fonte: https://developer.apple.com/design/human-interface-guidelines/color-wells
>
> Plataformas: ios,ipados,macos,visionos

*Um seletor de cor permite que as pessoas ajustem a cor de texto, formas, guias e outros elementos na tela.*

Um seletor de cor exibe um seletor de cores quando as pessoas o tocam ou clicam nele. Esse seletor de cores pode ser o fornecido pelo sistema ou uma interface personalizada que você projetar.

## Boas práticas

**Considere o seletor de cores fornecido pelo sistema para uma experiência familiar.** Usar o seletor de cores integrado oferece uma experiência consistente, além de permitir que as pessoas salvem um conjunto de cores que podem acessar de qualquer app. O seletor de cores definido pelo sistema também pode ajudar a oferecer uma experiência familiar ao desenvolver apps para iOS, iPadOS e macOS.

## Considerações por plataforma

*Nenhuma consideração adicional para iOS, iPadOS ou visionOS. Não é compatível com tvOS nem watchOS.*

### macOS

Quando as pessoas clicam em um seletor de cor, ele recebe um destaque que confirma visualmente que está ativo. Em seguida, ele abre um seletor de cores para que as pessoas escolham uma cor. Depois que fazem uma seleção, o seletor de cor é atualizado para mostrar a nova cor.

Os seletores de cor também permitem arrastar e soltar, para que as pessoas possam arrastar cores de um seletor de cor para outro e do seletor de cores para um seletor de cor.
