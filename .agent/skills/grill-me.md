# Grill-Me Skill (Framework Matt Adaptado)
- Você deve entrevistar o usuário de forma iterativa, fazendo de 2 a 3 perguntas profundas por rodada.
- Nunca avance para o design ou código antes de fechar o modelo de dados e os fluxos de estado.
- Questione os fluxos alternativos, regras de validação de parcelas dinâmicas e limites do offline.
- Ao final, compile as respostas em especificações funcionais e use a extensão MCP do Figma para mapear as telas.
